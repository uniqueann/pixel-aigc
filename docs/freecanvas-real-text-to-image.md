# 自由画布真实文生图交付

更新时间：2026-10-03。

## 功能与参数

文生图不需要上传原图。填写提示词后，可选择当前已配置的文生图模型、1:1 / 4:3 / 3:4 / 16:9 / 9:16 比例、数量与分辨率。新项目默认一张，分辨率读取现有个人图片设置；项目草稿优先，模型默认按服务端 defaultFor 或首个可用模型选择。本期未增加个性化设置项。

模型配置限制有效数量和分辨率。不支持的 4K 比例按现有规则降为 2K，提交前显示有效参数与积分预估。用户期望参数保存在草稿中，实际有效参数保存在生成请求中。文生视频和图生视频继续保留 Mock，在真实模式下说明尚未接入并禁用提交。

## 接口与数据

- `GET /api/capabilities` 返回 `textToImage`，模型目录沿用 `GET /api/image-models?operation=text_to_image`。
- `POST /api/tasks` 接受 `capability: text_to_image`、`requestId`、可选 `modelProfileId`，以及包含非空 `prompt`、正整数 `size.width/height`、`count` 与 `resolution` 的参数。真实请求必须包含分辨率，禁止传入原图或参考图字段。
- 模型与提示词长度在服务端校验，文生图向供应商发送空参考图列表，不读取或签名源图。结果按目标比例处理并记录实际尺寸、对象键与原始结果序号。
- 复用图片任务的限流、幂等、租约、积分预扣和实际成功张数结算；任务历史按能力筛选并正确分页。
- 既有数据库已支持 `text_to_image`，本次没有数据库迁移。

## 恢复与资产

请求在提交前落盘，任务号返回后立即保存。响应未知时先找回原请求，明确不存在才按同一个编号和请求体继续；失败或空结果不自动创建新任务。手动重试使用新请求编号，保留模型、有效参数与当前占位位置。

部分成功按原始序号落位，整批结果是一条可撤销命令；撤销后刷新不会重新插回。成功结果补存至我的资产，显示“文生图”，与图片工作站共用稳定结果 ID、账号隔离及删除记录保护。补存失败可单独重试，跨设备历史补记覆盖文生图。

画布与结果预览按对象键读取私有图片，使用运行时 Blob 租约；结果仍显示在预览区时，即使撤销画布节点也保留预览租约。本地与 JSON 保留模型、分辨率、任务恢复与有界撤销历史，兼容缺少新增字段的 schemaVersion 1 旧存档。高分辨率任务按宽高比例恢复预设。

云端保存图片、布局和参数草稿，完整任务历史与请求恢复仍限于本地和 JSON。旧 Mock 请求缺分辨率时不会直接发起真实付费任务。

## 验收

自动化验收覆盖无源图提交、参数校验、幂等扣分、部分成功及退款、配置门禁、重复点击、原请求找回、手动重试、资产补存、旧存档兼容、比例恢复、撤销后刷新及预览资源释放。

`npm test` 全量 148 个文件、837 项测试通过，`npm run lint` 与 `npm run build` 通过。独立本地 Mock 浏览器验收通过：新项目一张与个人分辨率、4K 比例降档提示、生成中刷新续接、整批撤销后刷新不复现、JSON 往返保留模型与分辨率，以及视频 Mock 生成和播放控制回归。页面无错误覆盖层与脚本异常。

尚未取得真实测试账号登录状态，供应商真实调用与实际积分扣款未执行。后续使用一张 1K 的小额生成核对结果对象、画布、资产与积分流水；供应商真实验收不能用 Mock 或自动化模拟替代。构建保留现有大包体提示，未扩展大规模画布性能专项。

千问图像 3.0 / 3.0 Pro 的后端适配在 `docs/qwen-image-integration.md`。`QWEN_IMAGE_ENABLED` 默认关闭，关闭时模型列表和能力开关与只接 GPT Image 2 时相同。
