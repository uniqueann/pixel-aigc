# 首页工作台

首期首页按「继续工作 → 快速开始 → 最近作品」排列，沿用现有登录、启动页偏好、全站主题与图片预览组件。此版本没有新增后端接口或数据库迁移。

## 页面内容

| 区块 | 内容 | 空状态与异常 |
| --- | --- | --- |
| 继续工作 | 最近 3 个画布、最近 3 个工具 | 没有记录时隐藏整个区块；云端读取失败时保留本机项目，并提供重试 |
| 快速开始 | 四组共 19 个独立入口 | 能力未知显示加载中；加载失败可重试；服务端明确关闭时显示即将上线 |
| 最近作品 | 此浏览器最近 8 项图片或未过期视频，横向滚动 | 无记录显示空状态；本地存储读取失败可重试 |

快速入口复用工具注册表中的名称与现有二级路由：

- 图片处理：智能编辑、重新打光、消除、重绘、扩图、精修、智能抠图、加水印、转比例。
- 批量出图：裂变、融合、流水线。
- 从零生成：文生图、文生视频。
- 邮件处理：回复、总结、润色、检查语法、批量邮件。

文生图和文生视频入口继续使用当前画布。邮件入口始终可进入，模型和自带密钥提示由邮件页处理。

## 继续工作与存档

最近工具和项目摘要保存在 `pixel:recent-work:v1:<origin>:<ownerId>`。摘要只包含工具地址、访问时间和项目名称、编号、更新时间、同步状态，不保存输入内容、文件或作品数据。导航记录只接受已知工具路由及邮件模式；首页和资产页不会覆盖最近工具。

首次使用时可从既有 `recent.page` 补入一个工具。流水线也被纳入合法偏好路由，启动页与最近页面设置继续使用原逻辑。

画布项目复用现有 IndexedDB 的账号存档，保存成功后才更新轻量摘要；首页不扫描完整画布。云端复用 `GET /projects` 和按账号划分、有效期 60 秒的 React Query 缓存。

合并项目时，当前账号正在编辑的画布排在首位，其余按更新时间排序。同编号只保留一项，尚未同步或存在冲突的本机存档优先于云端摘要。首页只展示当前账号的编辑器内容。

项目入口格式：

```text
/canvas/text-to-image?projectId=<编号>&projectSource=local|cloud
```

打开时先保存当前画布，再读取目标项目。尚未同步的画布需要确认保留本机存档；未完成生成、保存失败、同步冲突、没有编辑权或正在同步时阻止切换。选择当前项目直接返回原画布，可继续处理任务或保存问题。

读取过程中取消、换账号或继续修改当前内容，均会拒绝迟到结果。保存目标项目时，当前记录与项目存档在同一事务内更新，取消或存储失败会回滚。事务提交后再次检查归属，不能把原账号内容写入新账号编辑器。替换期间沿用持久化恢复页；成功后消费项目参数，刷新继续当前项目。

## 最近作品的读取边界

首页调用 `listHistoryPreviews(ownerId, true, { limit: 8, readOnly: true })`：

- 先筛选轻量元数据、排除到期视频，再读取最多 8 项缩略图。
- 不调用资产页的云端历史补记，不补读原图生成缩略图，不自动删除过期记录。
- 图片仅在点击预览时通过全站 `PreviewGallery` 读取原图。
- 视频无本机封面时展示图标和时长，仅点击后加载共享播放器。
- 缩略图地址使用 `useBlobUrls` 创建，记录移除、换账号和组件卸载时释放。
- 同账号的历史事件以 100 毫秒合并刷新，支持跨标签通知及页面重新获得焦点；其他账号的事件与迟到响应被忽略。
- 展示中的视频到期后重新读取本机列表；共享播放器继续执行到期及归属校验。

资产页原有调用默认行为保持兼容。

## 邮件入口

```text
/email?mode=single&operation=reply|summarize|polish|grammar
/email?mode=batch
```

显式快捷入口显示空白表单并预选操作，历史列表的慢响应不会自动覆盖。普通 `/email` 继续自动恢复最新历史任务。一次性的 `operation` 在处理后移除，`mode` 保留；单个和批量页签切换继续保留本页输入及批次。

同页进入另一项快捷操作时，先等待已编辑结果保存成功，再清空表单。正在生成或批量占用时保留当前输入并提示。页面卸载会失效旧任务选择，避免迟到历史写回任务状态。

## 布局与验收

快速入口在宽度至少 1200 像素时为 4 列，720–1199 像素为 2 列，小于 720 像素为 1 列。继续工作在窄屏排列为单列；作品列表独立横向滚动。

回归测试覆盖账号分区、存档原子回滚、慢响应取消、读取期间编辑、提交期间账号变更、严格模式重复副作用、画布切换确认、十九项入口状态、缩略图只读与地址释放、邮件快捷操作和普通历史恢复。

浏览器验收使用正式应用组件及独立受控数据，检查 375、768、1440 像素下无整页横向溢出，图片大图预览、本机项目恢复与草稿保留、取消切换、邮件模式与操作、流水线直达。验收环境关闭真实鉴权和云端连接，未调用付费生成或支付；云端慢响应与账号切换使用受控测试验证。

真实双账号登录、生产云项目恢复和真实视频播放仍需在部署环境验收。本期保留积分状态条、视频到期提醒、任务面板和统计面板的后续范围。
