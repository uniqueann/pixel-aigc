# 待办：智能裁剪的主体检测

> 转比例 M4 的第一步。检测模型或接口还没定，前端先不开发。九宫格焦点继续作为默认裁剪方式。

## 前端已经能接什么

智能裁剪用原图上的焦点 `fx`、`fy`（0 到 1）。`0` 贴起始边，`1` 贴结束边，`0.5` 是中心。九宫格是整批共用的默认焦点。

检测接口只需返回商品主体框。框的中心由前端换算成这一张图自己的焦点。检测失败时，这张图退回当前九宫格焦点，不整批失败。

## 建议接口

同步接口，不进生成任务队列。和智能选区一样，只返回几何，不生成新图。

```ts
{ box: { x: number; y: number; width: number; height: number } | null }
```

四个数都是相对原图宽高的 0 到 1。没有主体时 `box` 为 `null`。

## 准备清单

- [ ] 20 到 50 张真实商品图：白底主图、场景图、主体贴边、横图、竖图、一图多商品
- [ ] 每张图在 Amazon 主图 `1600×1600` 和抖音商品图 `1080×1440` 上各标一张可接受的裁切结果
- [ ] 一图多商品时的规则：取最大主体，或取最靠近画面中心的主体
- [ ] 确认检测不到时回退九宫格，不阻断这一张
- [ ] 选定能返回主体框的现成检测接口，确认单张耗时、20 张一批的费用，密钥只放服务端

不需要分割蒙版、自定义训练数据或新的平台尺寸。

## 接口就绪后再开发

- 每张图单独检测，成功则覆盖该图焦点，手动九宫格仍是默认值
- 批量检测沿用转比例队列；检测失败的图保持九宫格结果并标出原因
- 当前真实任务接口只接了邮件助手。这个检测要单独加一个小接口，不塞进扩图任务
