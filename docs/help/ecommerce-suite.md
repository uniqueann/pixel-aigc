# 电商套图使用指南

电商套图是专为跨境与国内电商卖家打造的一站式套图生成与排版工作台。只需上传一张商品主体图并配置规格，即可通过 AI 智能生成包含主图白底、多角度场景、细节特写、功能卖点和尺寸标注的标准 7 槽位套图，支持图层级自由微调与平台合规一键打包导出。

## 完整业务流程

```
上传商品图 → 配置规格与卖点 → 批量/单图生成 → 文字与图层微调 → 合规预检与成品导出
```

1. **新建套图项目**：上传高分辨率商品主体图，填写商品标题、类目与平台，配置规格与核心卖点。
2. **进入工作台编辑**：在 7 槽位间自由切换，随时查看出图进展并支持图层文字直观拖拽。
3. **出图生成**：支持单槽位针对性生成，或一键全套批量生成，后台异步处理无需停留在页面。
4. **文字排版与精修**：自由添加修改图层文字、一键引用商品规格；支持无缝调用图片工作站精修回填。
5. **合规检查与导出**：自动对照目标平台合规标准进行预检，通过后支持单张或全套 ZIP 打包下载。

## 第一步：新建套图与规格配置

在左侧主导航点击"电商套图"进入列表页，点击"新建套图"按钮：

1. **上传商品图**：
   - **商品主体图（必需）**：建议上传高分辨率白底图或单品主体图（单张不超过 20MB），作为整套图的核心视觉参考。
   - **补充参考图（可选）**：可上传实拍细节图、不同角度图或场景参考图，帮助 AI 更精准还原商品结构。
2. **基础信息与平台选择**：输入商品标题、可选 SKU、目标销售平台（如 Amazon 美国站）以及商品类目（家居家具 / 厨房餐饮 / 收纳家纺）。
3. **商品规格与卖点**：根据类目自动推荐常见参数（尺寸、材质、核心功能等），支持自定义添加标签；勾选"启用此项"即可将其作为后续排版文案的候选数据。
4. **选择槽位与统一风格**：系统默认启用标准 7 槽位，支持根据需要跳过不适用的槽位；选择整套图的主视觉风格后，点击"创建并进入工作台"。

## 第二步：工作台操作与槽位管理

工作台由左侧画板预览区、底部 7 槽位缩略条和右侧设置面板组成：

- **7 槽位状态指示灯**：缩略图右上角配有状态圆点（🟢 绿色：已就绪 / 🟡 黄色：生成中 / 🔴 红色：生成失败 / ⚪ 灰色：未生成），点击任意槽位即可切换工作焦点。
- **左侧画板与图层交互**：高保真预览当前槽位成品；支持直接在画板上选中并拖拽文字标签与尺寸标注。
- **工作站精修联动**：点击画板顶部"工作站精修"，可将当前画面发送至图片工作站进行局部重绘、智能消除或重新打光，精修保存后自动回填为新版本。

## 第三步：图片生成（单图与全套批量）

- **单槽位生成**：在右侧"生成设置"面板中，可查看当前槽位的定位建议，输入补充提示词（如光影方向、台面材质等），点击"生成当前图片"单独出图。
- **全套批量生成**：点击底部吸底栏的"全套批量生成"，勾选需要生成的槽位范围，确认出图分辨率（1K / 2K / 4K）和预估积分后提交。任务由服务端队列异步派发，即使关闭页面或离开浏览器，后台也会自动持续生成。

## 第四步：文字排版与版本管理

- **文字排版与图层微调**：在右侧面板的"文字排版与图层微调"中，可增删编辑主标题、副文案与尺寸标签；点击"引用规格"可一键抓取创建时填写的商品信息。文字与底图完全独立，可随时调整或撤回，不破坏底图。
- **版本管理**：右侧"版本管理"面板记录该槽位产生的所有图片历史（原图、AI 生成图、精修回填图）；支持一键"设为当前使用"，在多个候选方案中无损切换。

## 第五步：合规预检与成品导出

点击右下角"合规检查与成品导出"唤起导出抽屉：

1. **平台合规自动预检**：系统自动比对目标平台规则（如 Amazon 美国站主图要求：纯白底 RGB(255,255,255)、无水印文本、主体占比 ≥ 85%、尺寸 ≥ 1600px 等）。
2. **查看预检结果**：各项检查项显示通过、警告或阻断状态，并给出针对性修改建议。
3. **一键成品导出**：支持单张高清图下载，或点击"打包下载全套成品 (ZIP)"一键保存整套图片。

## 积分与计费说明

- **透明明示**：生成前各按钮均明确提示"生成 N 张 · X 积分"，避免意外扣费。
- **按实际成功结算**：生成积分先预扣，任务完成后只按实际生成成功的张数结算，失败或超时的任务自动退回积分。
- **排版与导出零费用**：在工作台中编辑文字排版、拖拽标注、切换历史版本、本地备份以及最终下载与打包导出，均不产生额外生成费用。
- **备份与恢复**：工作台顶部提供"备份与恢复 ▾"下拉菜单，支持随时下载本地草稿或导入 ZIP 恢复工程包。
