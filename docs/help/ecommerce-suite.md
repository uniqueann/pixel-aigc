# 电商套图使用指南

电商套图是专为跨境与国内电商卖家打造的一站式套图生成与排版工作台。只需上传一张商品主体图并配置规格，即可通过 AI 智能生成包含主图白底、多角度场景、细节特写、功能卖点和尺寸标注的标准 7 槽位套图，支持图层级自由微调与平台合规一键打包导出。

## 完整业务流程

```
上传商品图 → 配置规格与卖点 → 批量/单图生成 → 文字与图层微调 → 合规预检与成品导出
```

1. **新建套图项目**：上传高分辨率商品主体图，填写商品标题、类目与平台，配置规格与核心卖点。
2. **进入工作台编辑**：在 7 槽位间自由切换，随时查看出图进展并支持图层文字直观拖拽。
3. **出图生成**：支持单槽位针对性生成，或一键整套批量生成，后台异步处理无需停留在页面。
4. **文字排版与精修**：自由添加修改图层文字、一键引用商品规格；支持无缝调用图片工作站精修回填。
5. **合规预检与导出**：自动对照目标平台合规标准进行预检，通过后支持单张或全套 ZIP 打包下载。

## 第一步：新建套图与规格配置

在左侧主导航点击"电商套图"进入列表页，点击"新建套图"按钮：

1. **上传商品图**：
   - **商品主体图（必需）**：建议上传高分辨率白底图或单品主体图（单张不超过 20MB），作为整套图的核心视觉参考。
   - **补充参考图（可选）**：可上传实拍细节图、不同角度图或场景参考图，帮助 AI 更精准还原商品结构。
2. **基础信息与平台选择**：输入商品标题、可选 SKU、目标销售平台（如 Amazon 美国站）以及商品类目（家居家具 / 厨房餐饮 / 收纳家纺）。
3. **商品规格与卖点**：根据类目自动推荐常见参数（尺寸、材质、核心功能等），支持自定义添加标签；勾选"启用此项"即可将其作为后续排版文案的候选数据。
4. **选择槽位与统一风格**：系统默认启用标准 7 槽位，支持根据需要跳过不适用的槽位；选择整套图的主视觉风格后，点击"创建并进入工作台"。

## 第二步：工作台操作与槽位管理

工作台由左侧画板预览区、底部 7 槽位缩略条和右侧设置面板组成：

- **7 槽位状态指示灯**：缩略图右上角配有状态圆点（🟢 绿色：已就绪 / 🟡 黄色：生成中 / 🔴 红色：生成失败 / ⚪ 灰色：未生成），点击任意槽位即可切换工作焦点。
- **左侧画板与图层交互**：高保真预览当前槽位成品；支持直接在画板上选中并拖拽文字标签与尺寸标注。
- **工作站精修联动**：点击画板顶部"工作站精修"，可将当前画面发送至图片工作站进行局部重绘、智能消除或重新打光，精修保存后自动回填为新版本。

## 第三步：图片生成（单图与全套批量）

- **单槽位生成**：在右侧面板的"重生成"中，选择图片模型、分辨率与候选张数，点击"生成当前图片"即可一键派发出图，系统按实际成功张数结算积分。
- **整套批量生成**：点击页面顶部的"整套批量生成"按钮，在弹出面板中勾选需要生成的槽位范围，确认出图分辨率（1K / 2K / 4K）和预估积分后提交。任务由服务端队列异步派发，即使关闭页面或离开浏览器，后台也会自动持续生成。

## 第四步：文字排版与版本管理

- **文字排版与图层微调**：在右侧面板的"文字排版与图层微调"中，可增删编辑主标题、副文案与尺寸标签；点击"引用规格"可一键抓取创建时填写的商品信息。文字与底图完全独立，实时自动暂存。
- **版本管理**：右侧"版本管理"面板记录该槽位产生的所有图片历史（原图、AI 生成图、精修回填图）；支持一键"设为当前使用"，在多个候选方案中无损切换。点击面板底部的"固化为新版本"可随时将当前图层快照永久存档。

## 第五步：合规预检与成品导出

点击右下角吸底栏的"合规预检与批量导出"唤起导出弹窗：

1. **平台合规预检**：系统自动校验画板尺寸、格式与纯白铺底，并对照平台规范（如 Amazon 美国站主图尺寸范围、主图图层锁定等）列出合规检查清单。对于商品主体轮廓占比、底图是否有杂物水印等无可靠自动算法判定的项目，系统会列为人工复核项，提醒运营人员核对。
2. **自动保存图层版本**：若画板中有未固化的文字或图层修改，预检导出时系统会自动将其保存为新版本并设为当前使用，随后合成导出，确保导出成品与画板实时预览完全一致。
3. **查看预检结果**：各项检查项显示通过、警告或阻断状态，并给出针对性修改建议。
4. **一键成品导出**：支持单张高清图下载，或点击"下载 X 张成品 ZIP"一键保存整套成品包。

## 积分与计费说明

- **透明计费**：单槽位生成按所选模型、分辨率与张数预扣积分，并按实际成功张数结算；失败或超时全额自动退回积分。
- **实时余额同步**：出图完成时，顶栏积分余额自动同步刷新一次。
- **排版与导出零费用**：在工作台中编辑文字排版、拖拽标注、切换历史版本、更新本地备份以及最终合规预检与打包导出，均不产生额外生成费用。
- **备份与恢复**：在套图列表页支持点击"导入含图片恢复包"恢复历史工程；在工作台顶部"备份与恢复 ▾"下拉菜单中，可随时更新本地数据备份或导出项目恢复包 (ZIP)。
