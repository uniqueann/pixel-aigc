# 图片工作站总览

图片工作站是 8 个 AI 修图工具的集合。桌面端左侧是图片与预览、右侧调参数、底部点生成；移动端按上下顺序排列。所有工具都先明示积分才可提交。

## 8 个工具，一句话

| 工具 | 用来干什么 |
|------|-----------|
| 智能编辑 | 用文字描述改图：换背景、换颜色或材质、加元素 |
| 重新打光 | 用罗盘选主光方向，再调光线质感与色温；支持正面光与逆光 |
| 消除 | 涂掉路人、水印、瑕疵等不需要的东西 |
| 重绘 | 涂抹选区后按描述重新生成；固定使用通义万相 2.1 图像编辑模型，每次 1 张、与原图同尺寸 |
| 裂变 | 一张图变出多个版本，适合批量测款 |
| 融合 | 保留商品，把背景换成第二张图的场景 |
| 扩图 | 向外扩展画面，补全背景 |
| 精修 | 去瑕疵、提亮、边缘锐化、统一质感 |

## 通用操作

1. 选工具 → 上传图片（未上传时生成按钮置灰）。
2. 右侧调参数：生成数量、渲染分辨率、光线方向等；重绘固定为 1 张、与原图同尺寸，不提供数量和分辨率选择。
3. 看清底部"生成 N 张 · X 积分"，点击生成。
4. 结果满意可存入"我的资产"。

## 消除怎么用

1. 上传图片后，用画笔涂抹要消除的对象；也可以用智能选区点一下商品，自动选中整个轮廓。
2. 背景描述可选：小物体留空即可；大面积消除建议描述期望补上的背景（比如「干净的桌面」），不要写「删除 xxx」。
3. 画布只会修改涂抹区域，未涂抹的部分保持不变。

## 示例图怎么看

未上传图片时，上传区上方会给出三步示例，各工具共用同一套线型语法：

- **红色**：涂抹的蒙版，和画布上真实画笔的颜色相同；智能选区选中商品后也是这个颜色。
- **虚线框**：AI 实际会改动的区域。消除后它表示被补齐的背景，重绘中表示生成物所在的选区；融合中它标出「只取背景」的场景图；扩图里是绿色虚线框，也就是目标画布。
- **实线框**：原样保留、不会被 AI 改动的内容：融合里是商品保真，扩图里是原图像素边界。
- **气泡**：只对这一块选区生效的描述；重绘比消除多这一层因果关系。

## 重绘怎么用

1. 上传图片后，用画笔涂抹要重绘的区域。画布只会记录图片范围内的笔迹，图片外的涂抹不会生效。
2. 在右侧填写重绘描述（必填），描述该区域希望变成什么。
3. 生成成功后，原图、蒙版和描述都会保留，可以直接改描述再生成一版；把结果选为下一轮输入前会提示清空蒙版。

替换图片会清空当前蒙版，系统会先确认。

## 扩图怎么用

1. 上传图片后，画布上的绿色虚线框就是目标画布。
2. 拖四个角或四条边向外扩，也可以直接改右侧的目标宽高；扩多少就补多少，框内原图像素保持不变。
3. 「输出目标」三选一：自由扩展（原图原尺寸，只向外延伸画面）、平台比例（沿用原图分辨率，只改画幅比例）、平台尺寸（按平台精确像素缩放并补全背景）。

## 融合怎么用

1. 第一张上传要保留的商品图，第二张上传提供新背景的场景图。
2. 商品本身不会改变：形状、颜色、表面纹理、印刷文字和 Logo 都会保留。
3. 场景图只提供背景与氛围，不会把场景里的物体画进商品，也不会添加文字或水印。
4. 补充说明可选，用来描述场景、光线或构图；与商品保真约束冲突时，以保真约束为准。
5. 场景图槽位为空时可点「使用上次场景」，沿用最近一次用过的场景图；上传新场景或交换图片后会自动更新。
6. 点击商品图或场景图可放大查看细节，大图里能直接下载原图。

## 写好提示词的几个要点

- **消除**：小物体可直接留空让 AI 判断；不要写"删除 xxx"，描述"希望变成什么样"效果更好（比如"干净的桌面"）。
- **智能编辑 / 重绘**：描述目标状态而非操作，比如"把包换成红色"好过"修改包的颜色"；重绘描述为必填。
- **精修方向**（去瑕疵 / 提亮 / 边缘锐化 / 统一质感）是**多选项**，可同时勾选多个。

## 重新打光怎么读罗盘

- **罗盘**：中间是商品。平面光的实线箭头从哪个方向指向商品，主光就从哪里来；虚线指向投影落下的方向。下方的「正面光 / 逆光」表示光源在镜头方向还是商品背后。
- **正面与逆光**：正面光不画箭头，用镜头徽标表示光源在镜头方向，投影落在商品后方；逆光用商品背后的辉光和轮廓光表示，投影朝镜头。这样正面不会和底光混淆，逆光也不会和虚线投影混淆。
- **光线质感**：柔光过渡柔和，适合干净的棚拍；硬光对比更强，影子边缘更清晰。
- **色温**：暖色 / 中性 / 冷色只改变环境光、背景、投影和高光的光源色，不会改变商品本身的颜色。
- **预设**：不知道从哪开始，可以先用「棚拍柔光」「日落暖光」「冷调轮廓光」，再微调方向和参数。

## 计费与限制

- 智能编辑、裂变、重新打光、精修、融合按模型和渲染分辨率计价；消除、重绘、扩图按固定积分计价。生成前按钮会明示积分。
- 预扣积分，只按成功张数结算，失败自动退。
- 消除 / 重绘 / 扩图每人每小时 20 次、同时 2 个任务，触发限制按提示稍后再试。

## 智能选区怎么用

在消除、重绘等工具里需要指定区域时，用**智能选区**点一下商品，系统会自动选中点到的整个商品（点空会提示"没有点中商品，请点在商品上"），比手动圈选快得多。
