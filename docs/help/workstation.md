# 图片工作站总览

图片工作站是 8 个 AI 修图工具的集合，统一三段式布局：左侧调参数、右侧传图片、底部点生成。所有工具都先明示积分才可提交。

## 8 个工具，一句话

| 工具 | 用来干什么 |
|------|-----------|
| 智能编辑 | 用文字描述改图：换颜色、换材质、加元素 |
| 重新打光 | 调整光线方向和氛围，正面光 / 逆光等 |
| 消除 | 涂掉路人、水印、瑕疵等不需要的东西 |
| 重绘 | 选中区域按描述重新生成 |
| 裂变 | 一张图变出多个版本，适合批量测款 |
| 融合 | 把两张图的元素融合成一张 |
| 扩图 | 向外扩展画面，补全背景 |
| 精修 | 去瑕疵、提亮、边缘锐化、统一质感 |

## 通用操作

1. 选工具 → 上传图片（未上传时生成按钮置灰）。
2. 左侧调参数：生成数量、渲染分辨率等。
3. 看清底部"生成 N 张 · X 积分"，点击生成。
4. 结果满意可存入"我的资产"。

## 写好提示词的几个要点

- **消除**：小物体可直接留空让 AI 判断；不要写"删除 xxx"，描述"希望变成什么样"效果更好（比如"干净的桌面"）。
- **智能编辑 / 重绘**：描述目标状态而非操作，比如"把包换成红色"好过"修改包的颜色"。
- **精修方向**（去瑕疵 / 提亮 / 边缘锐化 / 统一质感）是**多选项**，可同时勾选多个。

## 计费与限制

- 按模型和渲染分辨率计价，生成前按钮会明示积分。
- 预扣积分，只按成功张数结算，失败自动退。
- 消除 / 重绘 / 扩图每人每小时 20 次、同时 2 个任务，触发限制按提示稍后再试。

## 智能选区怎么用

在消除、重绘等工具里需要指定区域时，用**智能选区**点一下商品，系统会自动选中点到的整个商品（点空会提示"没有点中商品，请点在商品上"），比手动圈选快得多。
