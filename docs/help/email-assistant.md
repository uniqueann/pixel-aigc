# 邮件助手与 DeepSeek Key 配置

邮件助手帮你写开发信、做润色、做总结，支持单封和批量两种模式。**它需要你自备 DeepSeek Key**。

## 为什么要自备 Key

邮件助手的 AI 费用由你的 DeepSeek 账号承担，不经过 Pixel AIGC 的积分系统。这样用多少花多少，价格透明；任务记录保留 7 天。

## 配置步骤

1. 去 [DeepSeek 开放平台](https://platform.deepseek.com) 注册并创建一个 API Key。
2. 打开 Pixel AIGC **设置 → 模型与密钥**，填入你的 DeepSeek Key 并保存。
3. 回到**邮件助手**，顶部横幅不再提示缺 Key，即可使用。

Key 只保存在你的账号下，不会展示给他人。

## 单封模式

粘贴或输入内容，选择操作类型（总结 / 回复 / 润色 / 检查语法），点生成即可。

## 批量模式

1. 下载 CSV 模板，按列头填写（收件人、主题、内容等）。
2. 上传 CSV，检查预览无误后提交。
3. 批量每小时最多处理 **60 条**，超量请分批。

## 常见问题

- **提示 Key 无效？** 检查是否复制完整、有无多余空格，确认 DeepSeek 账号有余额。
- **生成很慢？** 批量任务按队列处理，页面会显示进度，切走页面不影响，回来可继续看。
- **7 天后任务去哪了？** 任务记录只保留 7 天，需要长期留存请及时导出结果。
- **会用我的积分吗？** 不会。邮件助手只消耗你 DeepSeek 账号的额度。
