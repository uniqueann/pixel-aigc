# 快速上手

Pixel AIGC 是为电商卖家打造的 AI 图片工作台：商品抠图、场景重绘、批量出图、营销邮件，一站式搞定。

## 四大模块，一句话认识

- **图片工作站**：8 个 AI 修图工具——智能编辑、重新打光、消除、重绘、裂变、融合、扩图、精修，点开即用。
- **工具箱**：高频小工具——智能抠图、加水印、转比例（适配各电商平台尺寸），以及把"转比例 → 加水印"串起来的**流水线**。
- **自由画布**：从零生成营销图，文生图已可用，视频生成即将上线。
- **邮件助手**：用你自己的 DeepSeek Key，批量写开发信、做润色。

## 5 分钟做出第一张图

1. 用 Google 或邮箱注册登录，新账号自动到账 **30 积分**。
2. 打开**工具箱 → 智能抠图**，上传一张商品图（JPG/PNG，单张不超过 20MB）。
3. 点击"开始处理"，几秒后得到透明底商品图，直接下载。
4. 想继续加工？去**工具箱 → 转比例**选"Amazon 主图"一键改尺寸，再**加水印**打上店铺 Logo。

## 商品图上架标准流程（推荐）

```
实拍图 → 智能抠图 → 转比例（选目标平台预设）→ 加水印 → 下载 / 存入我的资产
```

这条链路在**工具箱 → 流水线**里已经串好：选好尺寸和水印，一次处理多张图，中途切走页面会暂停，回来可继续。

## 积分怎么花

- 每个生成按钮都会明示"生成 N 张 · X 积分"，点之前先看清楚。
- 积分先预扣，**只按实际成功的张数结算**，失败或超时自动退回。
- 智能抠图每月有 **20 张免费额度**，用完后 1 积分/张。

更详细的计费规则见《积分与计费说明》。
