# 积分与计费说明

## 积分是什么

积分是 Pixel AIGC 的使用额度，所有 AI 生成任务都按积分扣费。顶部栏常驻显示当前余额，点击可查看明细和购买。

新账号注册自动赠送 **30 积分**，可直接体验全部功能。

## 怎么扣费

- **图片任务**（图片工作站、自由画布）：按所选**模型和渲染分辨率**计价。每个生成按钮都会明示"生成 N 张 · X 积分"，自由画布还会显示"本次预计扣 N 积分"，点生成前先看清楚。
- **同步小工具**：消除、重绘 5 积分/次；扩图按轮次计费（页面会标明"最多 10 积分"）；智能抠图每月 20 张免费，超出后 1 积分/张。

## 预扣与结算

1. 提交任务时**先按请求张数预扣**积分。
2. 任务完成后**只按实际成功的张数结算**，多扣的部分自动退回。
3. 生成失败或超时**自动退积分**，不需要你手动申请。

所以放心点：没出结果，就不花钱。

## 购买与退款

- 点击顶部积分余额可购买：体验包 100 积分、常用包 320 积分、工作室包 1150 积分。
- 充值积分长期有效；赠送积分不折现。
- 现金退款需人工审核，只处理未使用部分，按原支付通道退回。
- 生成失败的自动退积分不走退款流程，直接回到余额。

## 查看明细

点击顶部积分 → 积分明细，可看到每一笔"充值 / 赠送 / 消费 / 退款"的记录，对账有疑问先查这里。

## 频率限制

为保证服务稳定，部分工具有频率限制：消除 / 重绘 / 扩图类每人每小时 20 次、同时最多 2 个任务；抠图 / 智能选区类每人每小时 60 次、同时最多 3 个任务。触发限制时按页面提示稍后再试，不会扣积分。
