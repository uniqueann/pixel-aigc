# 联系支持

## 反馈问题

遇到 Bug、有功能建议，或对扣费有疑问，欢迎直接联系我们。请尽量附上：

1. 出问题的页面和操作步骤；
2. 出错的截图；
3. 大概的发生时间（方便我们查日志）。

## 联系方式

- **邮箱**：support@contentup.cc
- **X（Twitter）**：[@uniqueann](https://x.com/uniqueann) 私信

一般 1–2 个工作日内回复。涉及扣费异常的，请附上积分明细截图，我们会优先处理。

## 在提问前

- 先看看《常见问题》，大部分"扣费 / 失败 / 限制"类疑问那里都有答案。
- 生成失败先去**积分明细**确认是否已自动退积分，再决定是否需要联系我们。
