# 自由画布使用指南

自由画布把素材、生成结果和编辑操作放在一个项目里。模型是否可用以页面状态为准，生成前可查看积分费用。

## 文生图

1. 选择文生图，填写画面描述，设置模型、尺寸和数量；比例下方会直接写出当前比例的含义与像素。
2. 确认预计积分，点击生成，等待结果进入画布。生成中的占位框会显示已用时长。
3. 移动或缩放图片，预览结果并下载。

## 空白画布

新建的画布是空白的，画板中央会给出三个示例描述：点一下直接填进"画面描述"，再把描述改成自己的内容就能生成。也可以跳过示例，直接用「添加图片」上传素材，或把图片从系统拖进画布。

## 添加图片与继续加工

通过“添加图片”上传本地素材，或从图片资产中选择已有作品。选中图片后，可使用当前开放的裂变、图生视频等操作，提交前确认对应积分。

## 视频生成

文生视频和图生视频仅在平台开放对应能力后可用。按页面选择模型、时长与参数，确认费用后提交。任务完成后可预览和下载，请留意作品保留时间。

MiniMax H3 文生视频和图生视频提供 768p 和 2K 两档，每次生成 1 条，支持 5 秒／10 秒，包含原生声音。768p 分别为 50／100 积分，2K 分别为 80／160 积分；Seedance 保留声音开关。图生视频以选中图片作为首帧，保持原图比例。生成前以页面实际模型与报价为准；原模型不可用时需要手动选择其他模型，已提交任务仍按原模型恢复。

## 画布与项目

- 滚轮平移，按住 ⌘/Ctrl 再滚动可缩放，按住空格可拖动画布；`⇧0` 回到 100%，`⇧1` 适合画板。
- 从系统直接拖入图片即可加入画布，落点就是鼠标位置。拖动图片时会显示与其它图片的左/中/右、上/中/下对齐参考线（只做提示，不会吸住）。
- 点选图片后按住 ⇧ 可加选，空白处拖动可框选；`⌘A` 全选，`Esc` 取消选择。图片被别的图片盖住时，按住 `⌥` 点击会逐层往下选中。
- `⌘D` 立即复制一份（不消耗积分）；`⌘C` / `⌘V` 复制到鼠标位置，适合把结果摆到别处。
- 方向键微调 1px，按住 ⇧ 微调 10px；`⌘]` / `⌘[`（加 ⇧ 为置顶/置底）调整叠放层级，也可以用节点操作条的「层级」。
- 工具条的「图层」按钮按叠放顺序列出画布内容，图片被压住或拖到画板外时用它找回来。
- 使用撤销和重做恢复编辑步骤。
- 顶栏显示项目名称及保存状态，可从项目菜单管理项目；离开前确认保存状态。
