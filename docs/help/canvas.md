# 自由画布使用指南

自由画布把素材、生成结果和编辑操作放在一个项目里。模型是否可用以页面状态为准，生成前可查看积分费用。

## 文生图

1. 选择文生图，填写画面描述，设置模型、尺寸和数量。
2. 确认预计积分，点击生成，等待结果进入画布。
3. 移动或缩放图片，预览结果并下载。

## 添加图片与继续加工

通过“添加图片”上传本地素材，或从图片资产中选择已有作品。选中图片后，可使用当前开放的裂变、图生视频等操作，提交前确认对应积分。

## 视频生成

文生视频和图生视频仅在平台开放对应能力后可用。按页面选择模型、时长与参数，确认费用后提交。任务完成后可预览和下载，请留意作品保留时间。

## 画布与项目

- 滚轮平移，按住 ⌘/Ctrl 再滚动可缩放，按住空格可拖动画布。
- 使用撤销和重做恢复编辑步骤。
- 顶栏显示项目名称及保存状态，可从项目菜单管理项目；离开前确认保存状态。
