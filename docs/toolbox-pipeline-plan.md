# 工具箱「转比例 → 加水印」短链

## 1. 已实现范围

入口 `/toolbox/pipeline`，工具箱显示「流水线」。一次上传、一次设置，按图片顺序串行完成：

**原图 → 留白填充 / 智能裁剪 → 可选文字 / Logo 水印 → 逐张 / ZIP 下载**

共用现有四个平台规格，一批选择一个规格。水印默认开启，未填写文字或选择 Logo 时阻止启动。关闭水印保留设置。上传沿用静态 JPG / PNG / WebP 校验：最多 20 张、单张 20 MB、整批 150 MB；桌面 24 MP，触屏设备 12 MP。

不包含智能扩展、抠图、资产保存、组合模板、后台运行和刷新恢复。不新增服务端接口、数据库、计费逻辑或自由画布改动。智能裁剪沿用现有主体检测接口及限流边界。

## 2. 页面与共享组件

- `PipelineTool` 负责上传、预览切换、参数、队列和下载操作。
- `AspectRatioSettingsPanel` 与 `WatermarkSettingsPanel` 为受控共享面板，原单工具也使用它们；流水线通过允许策略列表隐藏智能扩展。
- `PresetControls` 读取、保存和删除现有 IndexedDB 本机模板，按用户隔离；转比例列表过滤智能扩展模板。原单工具保留已有模板管理行为。
- `BatchImageUpload`、`BatchImageQueue` 和 `PreviewGallery` 共用。队列优先显示成品，再显示中间图，最后显示原图。预览可放大并与原图对比。
- 预览防抖 180 ms，最长边 800 px。开始前的裁剪仅按九宫格展示，不触发主体检测；已有中间图时，改水印只从该图更新预览。版本检查和清理阻止旧预览覆盖新设置。
- 处理中允许切换预览、选择图片和暂停；上传、删除、清空、参数和 ZIP 操作锁定。

首次初始化读取现有参数偏好，记忆中的智能扩展映射为留白填充。后续设置仅在流水线会话内改变，不覆盖单工具偏好。模板是显式保存的共享本机资源。

## 3. 状态与执行

模块位于 `src/features/toolbox-pipeline/`：

| 文件 | 职责 |
|---|---|
| `types.ts` | `PipelineArtifact`、图片与步骤状态、最终格式、结果失效规则 |
| `store.ts` | Zustand 内存会话，原图 / 参数 / 中间图 / 成品 / 当前选择 / 执行版本 |
| `executor.ts` | 可注入的串行执行器、启动校验、步骤提交、失败隔离及恢复 |
| `runtime.ts` | 渲染器、主体检测缓存、暂停、重复启动门禁及持续用户订阅 |
| `usePipelinePreview.ts` | 缩略预览、防抖、清理与版本隔离 |
| `usePipelineUrls.ts` | 展示图片引用，复用共享 Blob URL 生命周期 |
| `download.ts` | 根据实际 MIME 命名，筛选成功成品并生成 ZIP |

转比例、水印步骤使用 `pending / processing / succeeded / failed`，关闭水印时下游为 `skipped`。每次从最早未完成的步骤继续，已成功成品跳过。一次最多一个全分辨率渲染在途。

| 情况 | 恢复行为 |
|---|---|
| 转比例失败 | 当前图片停止，继续下一张；重试从原图开始 |
| 水印或最终编码失败 | 保留 PNG 中间图，重试只执行下游，不再检测主体 |
| 检测无主体、超时或报错 | 九宫格降级并保留黄色提示，继续生成成品；支持单张重新检测 |
| 主动取消检测 | 中断，不降级，不提交迟到结果 |
| 修改比例参数 | 清除中间图、成品和裁剪说明，等待再次处理 |
| 修改水印参数或开关 | 仅清除下游，保留中间图和裁剪说明，等待再次处理 |
| 下载 / ZIP 失败 | 保留处理结果，可重新下载 |

## 4. 图片与导出协议

`PipelineArtifact` 包含 `blob`、实际 `mimeType`、`width` 和 `height`。两个现有渲染请求新增可选 `outputMime`；未传时保持单工具原编码行为。主线程与 Worker 使用相同规则。

转比例中间图统一 PNG。下游读取实际结果尺寸和 MIME，将其包装为 File，不重复应用外部上传的 20 MB 限制。输出校验拒绝尺寸或格式不符的结果。

| 策略与输入 | 最终格式 |
|---|---|
| 留白 + 纯色背景 | JPEG，原透明区域按所选颜色铺底 |
| 留白 + 透明背景 | PNG |
| 裁剪 + JPEG 原图 | JPEG |
| 裁剪 + PNG / WebP 原图 | PNG，保守保留透明 |

不扫描原图透明像素，不提供额外格式选项。JPEG 仅在最终阶段编码一次，质量 `0.92`。水印关闭时 PNG 直接复用中间结果，JPEG 执行一次最终编码。

命名 `{原文件名主体}_{presetId}_watermarked.{实际扩展名}`；关闭水印去掉水印后缀。复用现有清洗和重名编号。ZIP 仅包含成功成品，成品总量超过 200 MB 时提示逐张下载。

## 5. 会话、隔离与资源

- 站内离页暂停，保留已提交成功步骤，将在途步骤恢复为待处理。返回后重建展示 URL，手动继续；刷新或关闭后需重新上传。
- 执行版本与用户标识共同保护提交；暂停会中止检测并停止 Worker。主线程回退不能强行打断浏览器内部编码时，等待其结束并丢弃迟到结果，期间禁止启动第二次全尺寸渲染。
- 用户切换或退出时，持续订阅清除流水线图像、参数与检测缓存，页面未挂载时仍有效。
- File / Blob 是会话引用，Object URL 仅属展示生命周期。共享 `useBlobUrls` 在副作用中创建、按 Blob 复用、替换 / 删除 / 卸载时回收，避免 React 严格模式中断渲染造成泄漏。
- Bitmap 使用后关闭，Canvas 清空，Worker 完成或中止后释放。

## 6. 验收记录（2026-10-03）

自动化覆盖步骤串联、下游续跑、单张失败隔离、参数失效、提前水印校验、格式分支、取消与迟到结果、重复启动、用户切换、命名和 ZIP 筛选，以及共享预览 URL 在严格模式下的回收。原工具既有校验、几何、模板、批量、主体检测与智能扩展测试继续运行。

对齐最新 main 后全量检查通过：`npm test` 为 152 个测试文件、869 个测试；`npm run build` 与 `npm run lint` 成功。构建仍有既有大分块及第三方注解提示，无新增检查失败。

本地浏览器使用实际 Worker / Canvas 解码和编码，检测服务为模拟模式：

- 透明 PNG、透明 WebP、JPEG、带 EXIF 方向照片及横竖混合输入输出尺寸正确；PNG 角点 Alpha 为 0，半透明边缘 Alpha 保持 128，纯色铺底 JPEG 角点为所选白色。文件签名、Blob MIME 和扩展名一致。
- 文字和 Logo 平铺均生成全分辨率成品。水印从转比例后的图像计算几何。
- 实际 ZIP 下载后通过 CRC 校验，三份成品名包含平台 / 水印后缀，扩展名与图片签名一致。
- 四个平台实际导出分别为 1600 × 1600、1200 × 1200、1000 × 1000 和 1080 × 1440。
- 流水线保存的 Logo 模板可在单水印工具读取、应用和删除；单工具保存的智能扩展模板不会出现在流水线列表。
- 20 张完成、暂停后迟到结果未提交、切页返回后继续；改水印保留 20 份转比例中间图。
- 移除 Worker / OffscreenCanvas 后主线程回退通过；关闭水印的 PNG 成品直接复用中间图，透明边缘与 Worker 路径一致。
- 文字水印渲染在 Worker 与主线程回退中，PNG / JPEG 的全尺寸输出及编码内容完全一致。桌面和 390 px 窄屏完成截图检查，窄屏无横向溢出；未做移动真机内存验收。
- 20 张重复处理后，展示 URL 计数保持 101；离页和清空后归零。此为活跃 URL 计数验收，不等同浏览器堆内存或移动真机峰值内存测量。

真实云主体检测的成功、超时和服务端限流尚未端到端验收；模拟主体检测及受控故障测试不能作为线上服务结论。首期代码继续复用既有检测接口与缓存，不改变供应商协议。
