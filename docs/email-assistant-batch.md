# 邮件助手批量生成

邮件助手顶部提供“单个”和“批量”页签。单个模式保留原有功能；批量通过 CSV 导入多封邮件，使用账号的默认邮件模型，按顺序逐条生成。

## 模板与导入

下载模板包含以下四列，采用 UTF-8 BOM 编码，不预填示例邮件。页面提供同列名的 PNG 截图，可点击放大。

| 列名 | 填写规则 |
| --- | --- |
| 原始邮件内容 | 必填，最多 10,000 字符，支持正文换行、逗号和引号 |
| 编写指导 | 可空，最多 1,000 字符 |
| 生成设置 | 总结、回复、检查语法、润色；可填写“润色：提升表达清晰度+缩短” |
| 语言 | 中文、英语、日语，或 zh、en、ja |

润色方式还支持“增长”“简化”，组合时用 `+` 连接。生成设置、语言留空时，使用导入时的个人默认设置；只填写“润色”时使用默认润色方式。预览表显示实际生效的设置。

单文件最多 50 条非空记录，文件不超过 5 MB。错误行也计入数量上限。允许调整列顺序或附加其他列；必需列缺失、重名、编码或 CSV 结构错误时拒绝整份导入。字段错误按记录标记，开始生成只处理有效记录。

预览表和结果表的第一列是「序号」，按文件里的非空记录从 1 递增，填写错误的记录也占序号。CSV 文件行号把表头算作第 1 行，因此第一条数据通常是「第 1 条（CSV 第 2 行）」。详情标题、错误原因，以及顶部汇总里点名的记录，都使用这个格式，例如「第 1 条（CSV 第 2 行）：原始邮件内容不能为空」。

## 执行与结果

- 一个账号同时只处理一条邮件；单个与批量共用页面提交锁。
- 暂停等待已经提交的当前邮件完成，再停止后续提交。继续生成不会重新处理成功行。
- 普通生成失败记录后继续；密钥、余额、限流或并发限制触发时暂停。现有后端每小时最多提交 60 次，重试同样受限。
- 响应丢失时按原请求标识查找任务，未确认终态前不提交下一行。无法查询时显示“待确认”，重新查询只恢复原任务。
- 重试已确认失败的任务使用新请求标识；未创建任务的提交重试保留原标识，先查找再提交。
- 批次首次开始时固定默认模型，暂停、继续、重试沿用同一模型。
- 详情可查看完整输入和结果，并复制生成文本。标题使用「第 N 条（CSV 第 M 行）」。
- 结果 CSV 不增加序号列，保留原始四列，附加生成结果、状态、错误信息。错误信息正文带有同样的序号前缀。文件包含错误记录和未完成记录，采用 UTF-8 BOM 和公式转义。
- 「总结」与单个模式提交相同的 `operation: summarize` 参数，并共用同一套提示词。结果是几条要点或一小段概述，不是带称呼和落款的回信。

## 会话与接口边界

批次只保存在当前邮件页面内存，页签切换保留输入、结果和进度。刷新、离开邮件页面或账号切换会停止后续提交；账号切换也会清空页面批次，并中止尚未发出的请求、忽略迟到响应。

已经提交到服务端的任务仍可在现有最近 7 天历史中查询。本功能复用 `POST /api/tasks`、任务详情和按请求标识查询接口，不增加后端批次存储或后台队列。

## 验证

自动测试覆盖 CSV、串行调度、暂停继续、失败重试、原请求恢复、账号切换，以及单个模式的回归。浏览器验证使用本地模拟生成；真实 DeepSeek 费用、限流和生成质量需要在真实账号环境单独验收。
