# 电商套图阶段五验收记录

基线 `main / 6cac7f9`，开发分支 `feat/ecommerce-suite-phase-five`。实现和回退边界见[阶段五说明](../../../ecommerce-suite-phase-five.md)。本目录记录代码及本地验证，不代表目标环境发布验收通过。

| 层次 | 证据与实际边界 |
| --- | --- |
| 逻辑与构建 | `gates.json`：全量测试、构建、Lint、契约及最终源文件哈希 |
| 独立 PostgreSQL | `postgres.json`：完整迁移链、实际 `aigc_api` 与原 SQL 账本，31 组；供应商和对象存储使用替身 |
| 数据库检查 | `advisors.json`：本机独立库检查，套图新增发现 0，保留 21 项既有警告 |
| 浏览器 | `browser.json`：真实 React → 本地真实 HTTP 业务接口 → 独立 PostgreSQL → 预检与实际文件编码；身份固定为本地测试账号，图片读取使用内存对象存储 |
| 文件 | 两张 PNG ZIP 及五条跳过清单实际解包、格式／像素／SHA-256 验证；PNG 1200×1000 与画板逐像素一致，JPEG 2000×2000 边角为白，WebP 4096×3413 实际解码 |
| 视觉 | 深浅主题，1440、1280×720、900、390、375×667；末项操作可滚动到可视区，无横向溢出 |

数据库在阶段四 26 组基础上新增：

1. 预检冻结历史事实与配置，稳定指纹与配置失效，跨账号及同槽多版本拒绝，零供应商和账本写入。
2. 回收站停止未派发项，恢复不重启队列，七天截止拒绝；清理默认关闭且无对象删除。
3. 原图片任务及无桥接同步输入引用保护，已知孤儿删除失败重试，清理隔离后禁止读取、写入或新预扣。
4. 原任务按原规则移除后才释放对象，并发领取互斥、旧令牌拒绝，完成标记幂等，供应商调用数与账本不变。
5. 内部维护身份、运行环境、普通角色清理标记权限及跨账号引用表 RLS。

浏览器显式制造一次对象读取 503；成功文件保留，重试仅重新读取失败文件。输出设置变化后旧检查失效，下载前对云端指纹的再核验拒绝已变化的配置。Amazon 最长边不足和主图透明铺底确定失败，其他可用槽位仍能导出；类目、主体占比和内容检查保留未知并要求人工确认。取消处理不下载半成品。整个浏览器流程没有提交生成任务，未处理异常与非预期控制台错误均为 0。

`annotated.png`、`annotated-4k.webp` 及截图中的商品均为代码绘制的合成样例，不计真实商品。完整 ZIP 仅在临时验收目录下载和解包，不加入仓库。缩略图与实际文件使用固定仓库字体，不依赖系统字体。

复现数据库：对本机空白独立 PostgreSQL 配置 `SUITE_TEST_DATABASE_URL` 与 `SUITE_TEST_DATABASE_CONFIRM=isolated`，运行 `npm run test:ecommerce-suite:postgres`。脚本拒绝业务库与非本机地址，应用完整迁移链；截止、退避与租约测试主动将时间置到期，不能当作真实七天或分钟调度证据。本轮临时数据库与浏览器服务均在结束后关闭并清理。

真实 Auth、R2、付费供应商外观与账单、目标环境迁移／定时器、具体卖家类目及回退演练仍待验收。真实商品保持 **0/9**，`phaseFiveExitPassed=false`。入口、派发、导出与清理继续默认关闭，未改远端配置或提交付费模型。
