浏览器覆盖文字与尺寸线、端点拖拽、键盘微调、20 层限制、历史完整切换与草稿归档、深浅主题成品像素不变、1280×720 短屏、900px 文档流、390／375px 无横向溢出及末项配置可滚动到可视区。工作站刷新仅 GET 读取会话；用户显式一次 POST 生成，重复回填仅一个候选且当前指针不变。实际下载图片恢复 ZIP 并再次导入，新项目保留图层与版本，移除原任务执行身份。本地恢复 ZIP 含多条草稿归档，上传与导入身份可重放。

数据库补充草稿并发、保存同键重放／异参、过时当前指针、伪造规格、无变化不建空版本、四类工具会话、精修／打光原图片任务、同步重绘五积分原账本、回填并发去重、合成图不重复叠字、过期拒绝、主图锁、旧规格快照不漂移及恢复收据。继承阶段三 20 组测试，调度时间仍主动置为到期加速，不能据此声称目标分钟调度完成。

复现数据库：对本机空白独立 PostgreSQL 配置 `SUITE_TEST_DATABASE_URL` 和 `SUITE_TEST_DATABASE_CONFIRM=isolated`，执行 `npm run test:ecommerce-suite:postgres`。脚本拒绝业务库与非本机地址，应用全迁移链后按实际应用角色验证；本轮临时数据库已停止并清理。

真实登录、R2、供应商外观与账单、目标环境调度和九个真实商品样本仍待验收。样本保持 **0/9**，`phaseFourExitPassed=false`；入口与维护继续默认关闭。阶段五的平台预检、批量成品 ZIP 与到期清理尚未实现。
