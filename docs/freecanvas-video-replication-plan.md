# 自由画布「视频复刻」首版方案

状态：方案已确认，待实现与内测。

## 产品定位

**用参考视频的拍法，拍自己的商品。** 面向电商卖家和内容团队，首版覆盖转台、商品特写、开箱和手持展示，参考素材以商品和手部为主。

例如，参考片是「手拧开水杯 → 杯口特写 → 桌面展示」。用户放入自己的水杯图，生成一条沿用相似镜头顺序和节奏、主体换成自家水杯的短片。优先保住商品的包装、轮廓和主色，再追求镜头相似度。

## 画布交互

1. **选参考片。** 在右侧生成栏选择「视频复刻」，可上传本地文件或从画布选视频。选中画布里的视频时，节点操作条提供「用作复刻参考」，点击后直接带入。素材卡支持预览和替换，超限时显示具体原因。
2. **放入商品图。** 上传或从画布选择一张商品图，可填写「补充要求」，例如「保持磨砂黑瓶身，背景改成浅木色」。参考片支持 2–15 秒、50 MB 以内的 H.264 MP4。成片默认取可用范围内最接近参考片的整数秒，可在 4–15 秒内调整。画幅默认取最接近原片的比例，可切换竖屏、横屏或方形。每次生成一条 720p 无声视频。
3. **看报价并生成。** 素材校验通过后显示本次积分。提交后沿用画布的排队、生成和转存状态。成片回到画布，选中它可以看到使用过的素材，并通过「沿用设置」修改要求再生成。

## 实现与计费

- **一次提交两种参考。** 首选通过 Vercel AI Gateway 接入 Seedance 2.0 Fast。参考视频提供镜头、运镜和节奏，商品图提供主体外观。官方接口支持两种素材一起传入，仓库已安装的 SDK 支持异步提交。真实成片质量和成本在内测中验证。[Seedance 2.0 Fast 接口](https://vercel.com/ai-gateway/models/bytedance/seedance-2.0-fast) · [异步视频生成文档](https://vercel.com/docs/ai-gateway/modalities/video-generation#start-and-status-calls)
- **复用现有视频任务。** 新增独立的「视频复刻」能力开关，在现有任务接口中增加复刻模式。任务参数包含参考视频 ID、商品图 ID、画幅、时长、补充要求和报价版本。首版沿用本地画布的视频生成入口。上传素材直传私有 R2，服务端校验归属和实际媒体规格，再为模型签发临时读链接。上传的参考片保留 7 天，过期后在素材卡提示重新上传。
- **参考片和成片时长共同决定报价。** 参考时长和输出时长各按 `≤5 秒`、`≤10 秒`、`≤15 秒`三档计算，内测成本与供应商账单对齐后配置积分。服务端在预扣前重算报价，价格变化时让用户重新确认。确认提交是否成功时沿用原请求，明确失败后才由用户发起新任务。

## 验收与开放

- 用 **12 组商品素材**覆盖转台、特写、开箱、手持四类场景，每类 3 组。每组首轮生成一条，至少 **9 组同时通过**商品外观和镜头节奏检查。主体轮廓、主色和可辨识包装须与商品图一致，参考片的主要镜头顺序和运动方向须可辨认。
- 验证本地上传与画布选片、素材过期与跨账号访问、刷新恢复、重复提交、退款，以及成片回填、播放和下载。真实成片与积分对账通过后，再向小范围用户开放。
