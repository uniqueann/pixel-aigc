# 自由画布 MiniMax H3 视频接入

## 范围与报价

模型厂商为 MiniMax，接入渠道为 Vercel AI Gateway。目录标识 `minimax-h3` 与渠道无关，实际调用模型为 `minimax/minimax-h3`。支持文生视频和单图首帧图生视频，每次一条，时长为 5／10 秒。文生比例沿用 1:1、4:3、3:4、16:9、9:16；图生保持原图比例。新草稿默认 H3、768p、5 秒，文生默认 1:1。

H3 统一为原生有声。官方 SDK 不支持 `generateAudio`，传入会产生参数忽略警告；本轮修正了上一轮把它当成可控声音开关的假设。页面改为固定说明，请求不传该上游参数，Seedance 继续保留声音开关，不新增去音轨处理。

| 分辨率 | 5 秒 | 10 秒 |
| --- | ---: | ---: |
| 768p | 50 积分 | 100 积分 |
| 2K | 80 积分 | 160 积分 |

价格版本为 `minimax-h3-video-v1`。当前网关目录生成费分别为 768p 每秒 $0.08、2K 每秒 $0.13；这是目录估价，不是已核实账单或利润。模型介绍页曾只列 2K，最新 SDK 文档与目录已列出 768P／2K；调用必须显式指定档位，不允许依赖默认值。

本期不包括 H3 Max、首尾帧、多参考、视频剪辑、任意时长和云端视频项目保存。Seedance 历史任务及原图生视频链路继续保留。

## 服务端配置与上线顺序

| 配置 | 作用 |
| --- | --- |
| `VIDEO_GENERATION_ENABLED` | 视频生成总开关，默认关闭 |
| `AI_GATEWAY_VIDEO_ENABLED` | H3 通道开关，默认关闭 |
| `AI_GATEWAY_IMAGE_TO_VIDEO_ENABLED` | H3 图生独立开关，默认关闭；必须同时满足视频总开关和 H3 通道开关 |
| `SEEDANCE_VIDEO_ENABLED` | Seedance 通道开关，默认关闭 |
| `AI_GATEWAY_API_KEY` | 复用现有服务端网关密钥；未配置时请求时读取 Vercel OIDC |
| `VIDEO_CRON_SECRET` | 复用现有分钟维护接口鉴权 |

H3 还要求现有数据库与 R2 配置就绪，不要求 Ark 密钥、Seedance 回调密钥或回调地址。只启用 H3 通道时开放文生视频；另开图生开关后才开放 H3 图生。已有 Seedance 环境升级时，需要显式设置 `SEEDANCE_VIDEO_ENABLED=true` 才保留新建 Seedance 任务的能力；原任务查询和后台推进不检查生成开关。

SDK 锁定 `ai@7.0.143` 与 `@ai-sdk/gateway@4.0.116`，运行于项目现有 Node.js 24。只新增视频适配器，共用网关鉴权，不修改图片或邮件的调用开关与参数。视频 SDK 使用官方默认地址，不使用图片 Chat Completions 的地址拼接规则。

上线顺序：先部署关闭开关的代码，再在受控环境验证参数、存储、恢复和费用；通过验收后才具备生产开放条件。本轮没有数据库结构迁移、新业务表或新任务状态，也不需要新增一套维护调度。

## 接口合同

`GET /api/video-models` 返回 Seedance 与 H3 的能力和报价。生成关闭时仍返回报价；每项的 `available` 和 `unavailableReason` 表示聚合可用性。`modes` 表示支持的生成方式，`availableModes` 表示当前实际开放的方式，前端不能仅使用聚合 `available` 判断图生入口。`audioMode` 为 H3 的 `native` 或 Seedance 的 `optional`。保留 `vendor`、`resolutions`、`pricing.creditsByResolution`；Seedance 原模型标识、价格版本和默认档位的 `pricing.creditsPerVideo` 保持兼容。

`GET /api/capabilities` 分别聚合文生、图生能力，不能用文生可用推导图生可用。所有密钥与 operation 均不返回给客户端。

`POST /api/tasks` 示例：

```json
{
  "capability": "text_to_video",
  "requestId": "11111111-1111-4111-8111-111111111111",
  "modelProfileId": "minimax-h3",
  "priceVersion": "minimax-h3-video-v1",
  "params": {
    "mode": "text_to_video",
    "prompt": "白色陶瓷杯置于木桌，镜头缓慢推进，柔和自然光",
    "size": { "width": 1024, "height": 1024 },
    "ratio": "1:1",
    "resolution": "2k",
    "durationSeconds": 5,
    "generateAudio": true,
    "count": 1
  }
}
```

`size` 用于现有画布放置与恢复合同，实际模型档位由 `resolution` 指定。服务端重新计算报价并校验模型、生成方式、分辨率和时长；不接受 H3 的 720p、无声或客户端自定义积分。旧价格返回 `VIDEO_PRICE_CHANGED`，不预扣、不请求供应商。原任务仍使用创建时的报价快照，修改目录不改变结算或退款金额。

图生沿用相同任务接口，将 `params.mode` 设为 `image_to_video`、`ratio` 设为 `adaptive`，增加属于当前用户的 `sourceImageKey`。服务端不信任客户端的外部图片 URL；从 R2 读取真实内容，预扣前校验静态 JPEG／PNG／WebP、20 MiB 上限、每边 256–5760 像素、宽高比 0.4–2.5，按 EXIF 方向记录有效宽高。Seedance 继续使用原 300–6000 像素限制。

H3 缺省声音参数按原生有声落盘；新建请求显式指定无声会在预扣前拒绝。旧请求仍先按原指纹查找既有任务，包括以前缺省或显式无声的 H3 请求，不改写历史参数；旧无声任务需要显式修改参数后才能创建有声的新任务。

## 异步任务、恢复与计费

1. 请求意图、参数指纹、供应商与报价快照、积分预扣在同一事务落盘。
2. `experimental_startVideo` 发起一次创建，关闭 SDK 自动重试，使用用户＋环境＋请求编号派生的稳定幂等键，提交超时 20 秒。
3. 网关任务编号保存在既有结果行；operation 连同参数警告保存至任务 `provider_params.operation`，仅服务端可读。
4. 页面查询与分钟维护读取任务保存的供应商及 operation，调用 `experimental_getVideoStatus`。后台不能将 H3 任务交给 Seedance，也不能因关闭生成开关而停止已有任务。
5. 完成后读取 URL 或内联结果，校验文件，再转存 R2，完成后才结算积分并进入画布／资产列表。

图生使用 `prompt: { image, text }`，图片为两小时有效的服务端 R2 签名 URL，不内联 Base64；Gateway 异步请求有 300 KiB 限制。图片存在时省略 `aspectRatio`，避免上游忽略比例而产生警告。实测原图尺寸保存于现有 `provider_params.sourceDimensions`，不依赖客户端 `size` 校验输出比例。

H3 首期使用轮询，不新增 Gateway webhook。原 Seedance 签名回调继续有效。保持 75 分钟任务截止、100 秒单次推进预算、15 分钟转存窗口，以及既有用户并发、全局并发和每小时限额。

| 故障 | 用户与账本行为 |
| --- | --- |
| 供应商明确拒绝、鉴权／额度异常 | 任务失败，退回预扣 |
| 创建响应丢失、网络失败、损坏的创建响应 | 保持提交确认中，不自动重新生成；无编号时截止退款 |
| 状态查询临时失败 | 保留任务编号与预扣，继续只读查询 |
| 参数被忽略或生成结果错档 | 失败退款，不静默改档、缩放或转码 |
| 下载／R2 暂时失败 | 在原转存窗口重试保存，不再次创建供应商任务 |
| 重复提交、重复维护 | 返回原任务，结算／退款各最多一次 |
| 任务超时后迟到成功 | 沿用既有免费补回规则，不再次收费 |

结果最大 100 MiB，必须为完整 MP4、H.264，存在音轨时为 AAC。H3 校验原任务音轨要求、时长误差不超过 0.5 秒，返回档位元数据时必须与所选档位一致。文生继续按固定比例尺寸校验；图生按实测原图比例校验，相对误差不超过 4%，768p 短边为 768±32 像素，2K 长边为 2048–2560 像素（边界容差 32），短边至少 992 像素。这是首期应用验收规则，真实样本不符时记录差异并保持入口关闭，不自动放宽、缩放或去音轨。结果 URL 仅允许 HTTPS、无凭证、无重定向；实际建连时拒绝私网 DNS 结果。视频仍保存于私有 R2，签名与保留期沿用原能力。

## 画布与草稿

文生与图生视频面板共用模型与分辨率选择，报价随所选档位／时长更新。新草稿优先选择可用 H3；历史模型不可用时保留原选择，提示手动选择，不把恢复任务切换到另一供应商。图生视频单独按模式可用性选模型，H3 不展示 Seedance 的人脸限制提示。

视频档位保存为普通和派生草稿的 `videoResolution`，避免影响图片 `resolution` 偏好；本地快照、项目 JSON、任务恢复与云端草稿校验均保留该字段及声音设置。用户编辑时一并保存实际模型和档位；旧草稿中明确的 720p 仍对应 Seedance，不因 H3 上线而自动换供应商。云端仅保存草稿，不因此开放视频资产的云项目保存。恢复沿用原请求，不重新上传或创建；手动重新生成使用新请求编号和原模型当前报价，并从可读原图重新上传首帧，避免复用过期临时对象。原图不可读时在生成前失败。资产列表显示实际模型与像素尺寸，计费说明同步列出两档报价。

## 验收证据与边界

自动化覆盖网关 SDK 请求映射、幂等键、创建不重试、状态与内联结果、分辨率报价、开关独立性、私网下载拒绝、数据库 operation 往返、共享余额、账号／环境隔离、重复维护、退款与迟到结果。画布覆盖报价切换、余额不足、历史模型选择与刷新恢复。

本地数据库测试使用 PGlite 执行真实迁移与事务；供应商和 R2 替身仅证明本地逻辑，不代表线上视频质量、供应商账单或生产存储验收。

本轮图生真实验收独立限制为最多四次创建、累计不超过 $5；失败或状态不确定的调用也占预算，不自动追加。四组合均为原生有声：768p／5 秒／16:9、768p／10 秒／9:16、2K／5 秒／1:1、2K／10 秒／4:5。目录估价合计 $3.15。逐项核对首帧一致性、实际尺寸、时长、音轨、可播放文件、R2、积分流水及网关费用；未取得实际账单时不能宣称成本验收通过。上一轮文生真实验收仍未执行，其声音行为现按原生有声修正，不能用本轮图生结果代替文生验收结论。
