# 自由画布真实裂变交付

更新时间：2026-10-02。

## 功能范围

用户可逐张上传 PNG、JPEG 或 WebP（最大 20 MB），或从当前账号的“我的资产”选择图片加入画布。新节点出现在当前视口中心并自动选中，每次添加是一条可撤销、重做的命令。同一私有图片重复添加可共享 Asset，节点的位置和变换分别保存。

选中图片点击“裂变”，填写可选变化描述，选择后端开放的模型、数量和分辨率。首次使用个人默认设置（默认两张、2K），后续优先恢复项目草稿。模型的数量上限、可选分辨率和比例限制会调整本次有效参数，并据公开积分报价显示预计预扣费用。

原图使用 Asset 的固有尺寸与内容，画布旋转、缩放和透明度不会烘焙进生成输入。已有私有对象复用对象键；本地原图先准备并上传，再提交真实 `variation` 任务。文生图、文生视频和图生视频继续沿用 Mock 演示。

## 提交与恢复

1. 原图准备或上传失败时，不提交任务、不创建占位。
2. 上传完成后先保存包含模型、分辨率、源对象键、账号和幂等键的原请求，再发送任务。
3. 快速重复点击共享同步提交门禁。拿到任务号后立即保存绑定，刷新后查询同一任务。
4. 响应未知时保留恢复意图，由用户点击“继续原请求”。先查询 `/tasks/by-request/:requestId`；找到则绑定原任务，明确 404 才用完全相同的请求续接提交，网络或服务异常保留等待状态。
5. 明确的请求拒绝（如 400、402、409、422）允许直接修改参数；未知网络结果和 408 保留等待。用户也可主动放弃等待。
6. 真实失败、取消或空结果不会自动创建新任务。手动重试使用新幂等键，保留模型、参数、血缘和当前占位位置；本地源图重新准备临时输入，避免依赖已过期的上传对象。Mock 派生任务保留原自动重试一次的行为。

后端按成功结果的原始 `ordinal` 落位，部分成功不会挤到前几个占位。全部成功结果由一条命令写入，失败位置统一清理。结果应用标记与项目一起保存，撤销或删除之后刷新不会重新插回。

## 图片与资产

私有图片通过共享对象读取器恢复，优先使用当前账号的本地原图或内存缓存，必要时重新签名。画布只使用运行时 Blob 地址；领域数据与 JSON 保留对象键和可恢复占位地址，签名过期时间不作为存档依赖。读取失败保留节点数据，可单独重试图片读取。

真实成功结果使用与图片工作站相同的任务序号 ID 补记到“我的资产”。补存尊重主动删除标记，重复补存不产生重复记录。历史保存失败可单独重试保存，结果和画布命令继续保留，不触发再次生成。所有异步写入检查账号、项目、存档版本与组件生命周期。

## 保存边界

- 本地与 JSON：图片、节点变换、生成血缘、表单草稿、模型、分辨率与请求恢复完整保存；兼容旧裸项目与 URL 输入的 Mock 恢复记录。
- 云端：兼容现有图片、布局和草稿；上传私有生成图片通过对象读取器取得原图。本地血缘不会因云端上传被清空。
- 云端重新打开：仍按现有契约恢复图片与布局，不恢复完整 Generation 历史或请求记录。完整备份使用 JSON；本次没有数据库迁移。

## 验收

自动化测试覆盖真实输入准备、重复点击、上传失败、失败后手动重试、响应丢失后的原任务找回、原样续接、部分成功落位、撤销后刷新、历史补存与删除标记、账号/项目切换、私有图片读取与资源释放、快照兼容。现有工作站、后端任务和积分结算测试一起运行。

浏览器验收使用独立本地 Mock 环境，验证页面与路由、上传后自动选中、默认两张/2K、生成中刷新续接、结果整批撤销后刷新不复现、资产入口以及 JSON 往返。供应商真实生成与真实积分扣款没有在本次本地浏览器验收中执行，需要登录测试账号后完成线上小额验收。

验证命令：`npm test`、`npm run lint`、`npm run build`。构建保留现有大包体提示；大规模画布的性能压力验收另属 Stage 4.6。
