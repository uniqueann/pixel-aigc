# 电商套图阶段四：图层、版本与工作站回填

基线：`main / aa76488`，PR #196 已合并；开发分支为 `feat/ecommerce-suite-phase-four`。本阶段代码和本地验证覆盖图层编辑、历史恢复、工作站会话与显式回填、PNG／JPEG 单图以及图片恢复包导入。证据见[阶段四验收记录](verification/ecommerce-suite/phase-four/README.md)。真实登录、R2、供应商、目标环境迁移和九个真实商品样本仍未验收，入口与维护开关继续默认关闭。

## 1. 图层与尺寸图

文字支持四种胶囊底色与透明、文字颜色、固定字体、字号／字重、宽度、对齐、层级和删除，每槽位最多 20 层，单文本最多 200 字。画板按实际底图比例展示，拖拽和百分比输入都使用成品坐标；方向键移动 1 像素，Shift＋方向键移动 10 像素。尺寸线有独立起点、终点与标签位置，标签由已确认的数值规格格式化，换算只改变显示，不改写原始值。

尺寸槽位优先复用用户上传的标注成品。没有标注参考图时，在持久商品原图上添加已确认尺寸／容量的可编辑尺寸线，不访问图片模型、不新增生成费用；缺少确认规格继续拒绝报价。自动摆放只提供初始位置，用户需核对方向、位置和测量对象，不能把视觉线段当成自动测量结果。

Amazon 美国站主图按 `kind: main` 锁定，不依赖序号；目前所有规则版本均禁止新增叠加图层，未知规则同样保守锁定。平台切换保留既有草稿和历史；保存版本、设为当前和单图导出再次校验。主图透明区域在预览与导出均铺白；这些约束不能证明底图无文字、水印或白底占比合规，平台预检仍属阶段五。

## 2. 草稿与完整版本

生成参数与图层共用一份槽位草稿和写入队列，800ms 防抖。事实、语言和单位可随草稿冻结，避免项目规格随后修改导致旧标签漂移。配置修订、草稿修订和当前指针修订相互独立；409 保留本机副本，可下载草稿、归档本机并读取云端。

`POST /api/ecommerce/suites/:id/slots/:slotId/versions` 接收原请求号、基准版本、预期当前指针与可选草稿修订、完整 composition。项目与槽位锁内分配版本号并追加 `annotation_edit`；已创建版本的相同保存请求返回原版本，同键异参拒绝。无实质变化不创建空版本，历史内容不能覆盖或删除。图层编辑不附加虚构模型或收费身份，真实来源沿父版本保留。

历史设为当前同时恢复底图、图层和本版本事实。切换前草稿保存到账号／环境隔离的本机归档，可单独下载，也包含在恢复包内。后台新结果与工作站回填均先存候选，不覆盖当前指针或本机未同步编辑。保存、导出、完整备份及进入工作站前刷新生成要求与图层草稿。

## 3. 共用绘制与单图文件

`render.ts` 的同一套 Canvas 2D 测量、中文与长文本换行、标签、线段及坐标缩放供预览与实际编码使用。固定 Noto Sans SC／Noto Sans WOFF2、字形覆盖及原始 OFL 许可随仓库分发，来源与哈希见[字体说明](../public/fonts/README.md)。英文图层含中文时固定回退到本地中文字体；字体读取失败或缺字时明确拒绝输出，避免系统字体悄悄替代。预览旧绘制被新草稿中止，选择框和手柄位于独立 SVG，不进入文件。

支持当前完整版本 PNG 与 JPEG，保持画板实际像素；JPEG 先明确铺白，PNG 保留透明度，Amazon 主图固定铺白。编码前检查成品 Schema 与图层越界，编码后重新解码核对格式与实际宽高；失败只重试读取或合成。单画板沿用 4000 万像素界限，位图和离屏画板及时释放，不隐式调用收费增强。

本地浏览器实际 PNG 解码像素与预览一致，4K JPEG 实际为 4096×3413。通用 WebP、输出尺寸／质量选择、平台预检和多槽位 ZIP 成品导出留在阶段五。

## 4. 四类工作站与回填

重绘、智能编辑、精修、重新打光使用原工具入口和费用确认。套图先保存当前版本，再创建七天会话；默认只传无叠加图层底图。主动选择合成图时先持久保存合成输入，并提示文字已烘焙；回填清空原独立图层，避免叠加两份文字。

URL 只携带不透明 `bridgeId`，不含图片地址、提示词或字节。工作站 GET 解析会话、重新授权读取输入并找回本会话已有成功结果；刷新、重登与结果列表读取不提交任务。原任务继续使用 `entry: workstation` 和真实工具，并携带可选 `suiteBridgeId`。服务端在原创建事务、预扣之前核验会话归属、环境、有效期、工具、实际输入对象及原请求关联；精修／打光参数也需匹配真实工具。普通工作站请求不读取桥接表。

用户显式选择本会话的成功候选后，`POST /api/ecommerce/bridges/:id/results` 核验原图片成功项或已结算重绘结果，再复制到套图长期资产并追加 `workstation_return`。同会话、同原结果及序号只有一个回填版本；回填请求号另有唯一保护。同键异参、无关联结果、跨账号／环境、项目在回收站或会话过期均拒绝，不产生收费生成。

所有回填先保存候选，来源已变或云端／本机草稿状态无法确认时不自动替换。画板变化按归一化坐标保留布局、按宽度缩放字号和笔画，并提示核对位置与规格；选用后仍可调整。任务中心返回原工作站任务时保留会话定位，费用不重复纳入套图父批次。账号或运行环境切换会中止旧输入／任务观察，拒绝晚到响应。

会话过期后，可回套图基于有权限的已保存版本重新创建会话；原工具结果仍遵循其自身访问和保留期。已回填版本与长期图片不随原任务清理失效；原任务已被清理且尚未回填时不能仅凭客户端对象键补造成功身份。

## 5. 图片恢复包

恢复 ZIP 保存配置、全部历史快照、当前指针、云端草稿、本机归档草稿和实际图片，移除对象键、短期地址、账号凭据及可执行批次／报价。下载前逐张校验字节与 SHA-256，全部相关图片成功读取才能形成完整包。

导入先校验格式版本、严格清单、唯一文件名、路径、CRC、实际解压大小、SHA-256、真实图片格式和像素，再让用户明确恢复到当前账号的新项目。恢复使用重新分配的槽位／资产／版本身份并重新上传；来源按已拥有的成品复用，不导入原收费任务权限、请求执行状态或队列。相同包的重试复用稳定创建、上传和恢复身份，服务端恢复收据使同内容只导入一次。恢复只允许本次创建、尚无编辑或执行的空白项目，不覆盖既有项目。

沿用 ZIP 200 MiB 与单图 20 MiB 限制；清单最多 8 MiB，2000 张图片／2000 个版本／1000 条本机归档，恢复 API 元数据受现有网关 3 MiB 上限约束，超限在创建项目和上传前提示。不会静默裁剪历史。恢复包与阶段五普通成品包使用不同清单格式。新项目未来生成仍需重新报价并确认。

## 6. 迁移、启用与回退

新增迁移：[20261017091705_ecommerce_suite_phase_four.sql](../supabase/migrations/20261017091705_ecommerce_suite_phase_four.sql)。新增不可变桥接会话、回填事件、恢复收据三表，全部使用实际 `aigc_api`、账号／环境 RLS、复合外键与最小追加权限；没有新增收费状态、特权领取函数或公共 Data API 授权。扩展原任务来源校验，并显式更新同步表依赖的旧函数 OID。
