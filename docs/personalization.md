# 个性化第一期

账号菜单的“个性化”直接打开设置。三组设置自动保存，默认值在下次进入工具或邮件“新建任务”时生效；云端刷新不会重置正在编辑的表单。

| 分组 | 内容 | 初始值 |
| --- | --- | --- |
| 工作台习惯 | 默认入口、记住侧边栏、资产布局 | 首页、开启、记住上次选择（首次网格） |
| 图片处理 | 五个工具分别设置数量、分辨率、记住上次参数 | 智能编辑/融合/精修 1 张，打光/裂变 2 张；2K；开启 |
| 邮件助手 | 输出语言、默认操作、润色方式 | 中文、回复、提升清晰度 |

侧边栏开合状态按账号保存在当前设备，手机自动收起。默认入口仅作用于首次访问根页面；直接链接和页面内返回首页保持指定目标。“上次访问页面”仅接受已知路由。

图片工作站和工具箱参数的优先级是有效任务/会话、开启后的工具记忆、个人默认值、工具初始值。关掉记忆开关保留旧记录，但暂停读写；清除记忆后下次进入工具使用默认值。模型或比例限制会同时调整表单和提交的有效数量/分辨率，不更改已保存的偏好。自由画布继续保存项目草稿。

图片记忆包括生成数量、分辨率、精修方向、打光选项、扩图方式与平台、抠图背景、转比例策略/尺寸/背景/输出方式，以及文字水印和布局参数。不保存上传文件、Logo 文件或模式、提示词、遮罩、裁剪焦点和生成结果。恢复默认会清除图片参数记忆及当前设备侧边栏缓存，需要确认。

## 存储与接口

`aigc.user_preferences` 使用 `(user_id, scope)` 主键及版本化 JSON。RLS 只允许当前环境的有效账号访问自己的配置，普通浏览器角色没有表权限。API 从认证事务取身份和环境，客户端不能指定用户。

- `GET /api/preferences`：读取配置，未初始化返回默认值和标识。
- `PATCH /api/preferences`：`{ patches: [...] , initializeOnly?: boolean }`，白名单字段补丁按顺序合并，同一字段最后提交生效。`image.lastUsed: null` 清除记忆。
- `POST /api/preferences/reset`：写入完整默认值，保持已初始化状态。

同账号同环境的写入通过事务锁串行合并。首次云端无记录才导入本机旧资产布局、抠图和转比例偏好；初始化竞争不会覆盖已有记录。前端缓存以来源地址及账号隔离，300ms 防抖，保存失败保留待提交补丁并提供重试。启动、打开设置、窗口重新获得焦点和网络恢复时刷新；账号切换后丢弃迟到响应，请求也验证令牌账号。
