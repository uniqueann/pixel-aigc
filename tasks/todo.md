# 首页优化（impeccable）

目标：在保留现有内容、路由与暗色创作工具视觉体系的前提下，优化工作台首页的信息密度、宽屏表现与空状态。

## 计划

- [x] 快速开始：四张等高卡片改为一套工具目录面板（分组 4 / 2 / 1 列，图片处理双列入口，去掉流程箭头）
- [x] 页面容器：增加 1280px 最大宽度并居中，避免 1920 下内容被拉长
- [x] 最近作品：说明文字仅在同步时显示；空状态改为紧凑行并给出「去画布创作」入口
- [x] 继续工作：两栏改为内容高度，消除单侧大片留白
- [x] 浅色主题：作品横向滚动条不再强制深色
- [x] 移动端：隐藏分组右侧说明、提高工具链接触控高度
- [x] 不可用工具文字对比度提升到次级文字色
- [x] 清理无引用的旧首页卡片样式
- [x] 运行 typecheck / lint / dashboard 测试 / 设计检测器，并重新截图核对 1440、1024、768、375 与明暗主题

## 验收

- [x] 19 个工具入口数量与路由不变
- [x] 无整页横向溢出（含 320px）
- [x] 空状态、加载、错误、不可用状态均保持可用

## 复查

- 渲染核对：1440 / 1920 / 1024 / 768 / 375 / 320，暗色与亮色；无控制台错误。
- 测试：`npx vitest run` 314 个文件、2041 个用例全部通过；前端 `tsc --noEmit` 与 ESLint 通过。
- 设计检测器仅命中 `global.css` 中既有的任务恢复条 `border-left: 3px`，与本次首页改动无关，未顺手修改。
- 数据与路由未变：`QUICK_START_GROUPS`、`ToolEntry`、`/email?mode=...` 等入口保持原样。

# 邮件助手批量审阅流程优化（impeccable）

目标：让导入后的批次摘要、生成动作与结果成为页面主线，模板说明降级为可展开的辅助信息。

## 计划

- [x] 模板说明改为默认收起，导入成功后自动收起；用主题自适应的 HTML 规则表替代白底截图
- [x] 导入后切换为紧凑文件条（当前文件 / 条数 / 替换文件），保留「保留当前文件」退出替换
- [x] 顶部批次摘要条：文件、计数、预计耗时、生成/暂停/重试/清空/导出与进度
- [x] 结果区前移并成为主内容；无数据时使用轻量空状态，不渲染空表格
- [x] 表格列重排：状态提前、结果列在有结果后才出现，桌面列宽合计 100%
- [x] 小屏结果行只保留状态、原文、操作；原文单行截断，其余字段进详情
- [x] 详情弹窗增加上一条/下一条、只读标识与只读底色
- [x] 清空批次、替换 CSV 增加确认；清空后提供 5 秒撤销
- [x] 确认生成框补充每小时 60 条的预计耗时
- [x] 本地模式隐藏模型/积分 UI，仅保留有效条数；无可用模型时给出提示
- [x] 无障碍：页面 h1、卡片 h2、输入框 aria-label、占位符对比度、焦点环、跳转到主内容链接、摘要 aria-live

- [x] 清空/替换均有确认，清空可撤销；生成确认含耗时
- [x] 小屏无横向溢出，结果行高度明显下降
- [x] 2042 个用例全部通过；`tsc --noEmit` 与 ESLint 通过
- [x] 设计检测器仅剩侧边栏既有对比度问题与上传拖拽区「嵌套卡片」误报
